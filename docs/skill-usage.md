# Skill の使い方 (Claude Code と対話しながらチューニング)

このリポジトリには Claude Code 用のスキル `aidt-tuning` (`.claude/skills/aidt-tuning/`) が入っています。
aidt の自動処理と、LLM による判断・説明・対話を組み合わせてチューニングを進められます。

役割は次のように分かれています。

- **aidt**: 計測・検証・書き込みなど、確実さが要る処理
- **Claude**: 解析結果の解釈、パイロットの感想との突き合わせ、方針決め、フライトプランやレポートの作成

## 準備

1. [セットアップ](setup.md) の 1〜2 を行います。uv のインストール、クローン、`make setup` です。
2. **機体を USB 接続する PC で**、このリポジトリを Claude Code (CLI またはデスクトップアプリ) で開きます。
   ```bash
   cd ai-drone-tune
   make skill      # = claude (Claude Code を起動)
   ```
   スキルは自動で読み込まれます。`/skills` で `aidt-tuning` が表示されれば準備完了です。

> クラウド上のセッション (claude.ai/code など) からは USB の機体に接続できません。
> その場合は、既存のログファイルを使った解析・計画・レポート作成に限られます。

## 話しかけ方の例

| やりたいこと | 話しかける例 | スキルの動き |
|---|---|---|
| 飛行後の解析とチューニング | 「機体をつないだ。ログを見てチューニングして」 | 状態確認 → ダウンロード・検証・消去 → 解析 → 結果の説明 → 変更案 → **了承後に**適用 → ジャーナルに記録 |
| 症状からの調整 | 「プロップウォッシュが気になる」「フリップ後に跳ね返る」 | 解析結果と感想を突き合わせ、小さな変更を提案する |
| データが足りないとき | 「どう飛べばいい？」(不足時はスキルから案内する) | 不足している理由、推奨する Blackbox/FC 設定、不足分だけの飛行手順 (モード・スロットル開度・回数・時間・電池本数) を示す |
| レースの記録 | 「明日のレース、3 分 × 4 ヒートのデータを取りたい」 | Flash に収まる記録レートを計算して設定を提案する。レース後に実戦データを解析する |
| 状況の把握 | 「今どういう状況？」「これまでの経緯をレポートにして」 | 履歴・ジャーナル・前回比較からレポートを作る |
| 直接の変更 | 「ロールの D を少し上げて」「最大レート 850」 | `--dry-run` で内容を確認して提示し、了承後に適用する |
| 元に戻す | 「さっきの変更を戻して」 | rollback の内容を示し、了承後に実行する |

## 安全のためのルール (スキルに組み込み済み)

- **FC への書き込みは、変更内容と理由を示し、ユーザーが了承した後だけ行います。**
  aidt 側も、`--yes` がないと書き込みません。アーム中の機体には書き込みません。
- 1 回の変更は小さくします (各設定 ±15% 以内が目安)。
- 書き込み前に `diff all` をバックアップし、書き込んだ値を読み戻して確認してから保存します。
- 書き込み後は、プロペラを外した状態でのモーター温度確認や、短いテスト飛行を促します。戻し方も伝えます。
- 解析に必要なデータが足りないときは、PID の変更は提案しません。まず飛び方や記録設定を案内します。
- Rate (パイロットの好み) は、頼まれたときだけ変更します。

## 典型的な 1 サイクル

1. 「飛ぶ前に記録設定を確認して」
   → FC の Blackbox 設定と Flash の空きを確認し、必要な設定変更とフライトプランを提示します。
2. プランに沿って飛行します (例: ホバー、スロットルスイープ、各軸のスナップ入力、パンチアウト、スロットルカット)。
3. 「つないだ。解析して」
   → ダウンロード・解析・データ十分性の判定・変更案を出します。足りなければ追加の飛行を案内します。
4. 感想を伝えます (例: 「ダイブ後に揺れる」)。
   → 変更案を調整し、了承後に適用します。
5. もう一度飛んで接続します。
   → 前回との比較 (良くなった / 悪くなった指標) を示し、次の一手を提案します。

## スキルが使うコマンド

スキルは `uv run aidt <command> --json` の形でコマンドを呼び出します。
同じコマンドを人が直接使うこともできます。詳細は [コマンドの使い方](cli-usage.md) を参照してください。

| コマンド | 用途 |
|---|---|
| `status` | 接続機体、Flash、Blackbox 設定、前回の変更、ジャーナル |
| `propose` | DL → 解析 → データ十分性 → 変更案 (書き込みなし) |
| `check` / `plan` / `preflight` | データ不足の判定 / フライトプラン / 接続 FC の記録設定チェック |
| `apply --yes` / `set --dry-run` → `set --yes` | 変更の適用 (了承後) |
| `compare` / `history` / `journal` | 前後比較、履歴、ジャーナル (状況レポートの材料) |
| `rollback --yes` | 元に戻す (了承後) |
